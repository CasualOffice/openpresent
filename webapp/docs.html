Early preview. OpenPresent views, presents and exports decks today; it does not edit them yet. Nothing here claims to look exactly as PowerPoint draws a slide: our output has not yet been checked against PowerPoint itself, and the gallery compares it with LibreOffice instead.

Open a deck

Open the editor and choose File → Open (Ctrl+O), or drop a file anywhere on the window. The deck is read by the engine, compiled to WebAssembly and running in your own browser; it is never uploaded.

The thumbnail pane on the left shows every slide. Click one to show it in the middle. The status bar says which slide you are on and how many there are.

Which files

ExtensionWhat it is
.pptxA presentation
.pptmA presentation with macros. The macros are kept in the file and never run
.ppsx, .ppsmA slide show, opened like a presentation
.potx, .potmA template, opened like a presentation

The old binary .ppt format, from before 2007, is not read.

Damaged decks

A deck that another program refuses often still opens here. A truncated or padded archive, a missing or broken content-types part, broken relationships and malformed XML each get the best reading the engine can make, and the rest of the deck opens. What was repaired or set aside is recorded rather than hidden.

Only a file with nothing readable in it is refused. The message names an error code you can quote in a bug report, and never the content of your file.

Move between slides

Use the arrow keys, Page Up and Page Down, or the space bar. Home and End go to the first and last slide. The View tab has Reading View, which fills the window with the slide (Esc leaves it), and Fit to Window.

Present

Slide Show → From Beginning (F5) or From Current Slide (Shift+F5) shows the deck full screen. Move on with a click, the right arrow, Page Down, Enter or the space bar; go back with the left arrow or Page Up. Esc ends the show.

Slides are shown as they are drawn in the editor. Transitions and animations are kept in the file but not played yet, and there is no presenter view yet.

What a slide leaves out

The renderer is not finished, and it says so. When a slide uses something that is not drawn yet, the status bar says so, and File → Info → What this slide leaves out lists each feature by name. Nothing missing is passed off as drawn.

Save

File → Save (Ctrl+S) or Save a Copy writes the deck back as a .pptx. Since nothing can be edited yet, what you get is the deck you opened, byte for byte. In the browser it arrives as a download; on the desktop, where you choose.

PDF

File → Export → Create PDF writes every slide as one page of a PDF. The text in it is real text, so you can search it and copy it, rather than a picture of text.

PNG

File → Export → Export Slide as PNG saves the current slide as a picture 1920 pixels wide, its height following the slide's own shape.

The desktop app

The desktop app wraps the same editor and engine in a native window for macOS, Windows and Linux. Open a deck from its Open panel, or double-click a .pptx, .pptm, .ppsx, .ppsm, .potx or .potm once the app is installed. It needs no network. See Download for where to get it and what your system will say the first time.

Privacy and safety

  • Your deck is read in your browser, or in the desktop app, and is never sent anywhere.
  • No macro ever runs. Macros in a .pptm are kept so the file is not damaged, nothing more.
  • Pictures and links that point outside the file are never fetched.
  • Every file is treated as hostile: archive bombs, entity expansion and path tricks are neutralized, and no text from a deck is ever put into the page as HTML.

Limits

  • No editing yet. Editing text comes next, then moving and resizing shapes, then building slides. The ribbon shows those commands already, disabled, so you can see where each will be.
  • Drawing is not complete. Some features are not drawn yet; each is named, as described under What a slide leaves out.
  • No transitions, animations or presenter view in the slide show yet.
  • No co-editing yet.
  • Not checked against PowerPoint. Before a release, our output is checked in PowerPoint itself. Until then, nothing here claims to match it.

Report a problem

A deck that opens wrongly, attached to an issue on GitHub, is the most useful thing you can send. Only attach a file you are free to share. For a security problem, follow SECURITY.md instead of opening a public issue.
