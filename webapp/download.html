OpenPresent on your desktop.

The same editor and engine as the web version, in a native window: your decks stay on your machine, a .pptx opens by double-click, and it works with no network at all.

Ubuntu 23.04 or later. Why.

Your computer will stop you once. Here is why, and what to do.

Signing an application means paying Apple or a certificate authority to vouch for it. This project has not done that yet, so each operating system treats these builds as being from an unknown source. That is a fair thing for them to do, and it means you should only ever take this step for a file you downloaded from this project's own GitHub page.

macOS

Unzip the artifact and drag OpenPresent.app to your Applications folder. A GitHub artifact does not keep file permissions, so the program inside the app needs its executable bit back, and the “downloaded from the internet” flag has to be cleared. In Terminal: 

chmod +x /Applications/OpenPresent.app/Contents/MacOS/*
xattr -dr com.apple.quarantine /Applications/OpenPresent.app

If macOS says “OpenPresent is damaged and can’t be opened”, it is not damaged: that is the wording macOS uses when it cannot validate a signature. The two lines above are the fix. Instead of the second line you can open System Settings → Privacy & Security, find the message about OpenPresent, and click Open Anyway.

Windows: “Windows protected your PC”

Unzip the artifact and run the setup program inside. SmartScreen hides the button by default: click More info, then Run anyway. There is no command to run and nothing to change in your settings.

Linux: the .deb needs Ubuntu 23.04 or later

It depends on libwebkit2gtk-4.1-0, which does not exist before Ubuntu 23.04. On 22.04 the install fails with an unmet dependency; use the web editor there for now. There is no AppImage yet. 

sudo apt install ./OpenPresent_*_amd64.deb

Not ready to install anything? The web editor is the same engine, with no download, and your deck never leaves your browser.
