Your PowerPoint decks, open anywhere.

OpenPresent is an open-source presentation editor built for PowerPoint files. Today it opens a .pptx in your browser or on your desktop, shows every slide, presents it full screen, and exports PDF and PNG. Editing is coming next.

01 Real renders, not mock-ups

Slides drawn by our own engine.

Each picture is the first slide of a real deck, drawn by OpenPresent's renderer when this site was built. The slide gallery shows every slide of every deck beside LibreOffice's rendering of the same file, so you can judge the difference yourself.

The decks are unmodified and keep their own licences; the full list is in fixtures/real. The reference beside them in the gallery is LibreOffice, not PowerPoint: until our output has been checked against PowerPoint itself, nothing here claims to match it.

02 What it is

A presentation editor for PowerPoint files, built in the open.

The ribbon, tabs and shortcuts of the presentation app you already know, over an engine whose first job is to keep your file intact.

.pptx · .pptm · .ppsx · .potx

Opens your decks. Never drops anything quietly.

Shapes, text, pictures, tables, charts, SmartArt and themes are read into one model. Anything the model does not hold yet is kept byte for byte, and what a slide uses that is not drawn yet is named, feature by feature, in the editor. Saving a deck you have not changed gives back the same bytes.

Recovery

Opens damaged decks.

A truncated archive, broken XML or a missing content-types part gets the best reading we can make, and the deck opens. Hostile content is neutralized rather than obeyed, and only a file with nothing readable in it is refused, naming why.

Slide show · PDF · PNG

Present and export.

Full-screen slide show from the start or the current slide. A PDF of the whole deck, with real text you can search and copy, or the current slide as a 1920-pixel PNG.

macOS · Windows · Linux

A desktop app too.

The same viewer in a native window. Open a deck from the Open panel, or double-click a .pptx; no network needed.

Private by design

Your file stays with you.

The engine runs in your browser as WebAssembly. Nothing is uploaded, no macro ever runs, and links inside a deck are never fetched.

Apache-2.0 · Rust · no telemetry

Open source, all the way down.

Every line is on GitHub: the engine, the editor and the desktop shell. unsafe is forbidden, every parser is bounded and has a fuzz target, and coverage of the file format is measured row by row rather than claimed. Decks that open wrongly, attached to an issue, are the most useful thing you can send.

03 Shipping now

What works today

A list of what the editor does now, not a roadmap. What is still to come is under Honest status below.

Open

  • Pick a file, or drop it on the window
  • .pptx, .pptm, .ppsx, .ppsm, .potx, .potm
  • Damaged decks get a best reading
  • A file that cannot be read is named with its error code

View

  • Thumbnail pane, slide and status bar
  • Shapes, fills, lines, effects, pictures and text
  • Tables, charts and SmartArt
  • What a slide leaves out, listed by feature

Present

  • Slide show from the beginning (F5)
  • Or from the current slide (Shift+F5)
  • Reading view and fit-to-window zoom
  • Arrow keys, Page Up and Page Down, Home and End

Save and export

  • Create PDF: every slide, with searchable text
  • Export the current slide as PNG
  • Save gives back an unedited deck byte for byte
  • In the browser and on the desktop

Not yet. Editing text and shapes, building slides, presenter view, transitions and animations in the slide show, and co-editing. The ribbon already shows those commands, disabled, so you can see where each will be.

04 Self-hosted

Put the editor on your own site.

The editor is static files: HTML, JavaScript, CSS and one WebAssembly engine. There is no server component, because a deck is opened and drawn in the visitor's own browser and never sent anywhere. Any web server, or any static host, will do.

The self-hosting guide Clone on GitHub
terminalwasm-pack
# build the engine into the editor's folder
$ wasm-pack build crates/casual-slide-wasm --release \
    --target web --out-dir ../../webapp/pkg
# then serve webapp/ from any web server
$ python3 -m http.server -d webapp 8080
No server code

Nothing to run, patch or scale beyond serving files.

Your network only

No document leaves the browser, nothing phones home, no licence check.

Strict CSP

The page carries its own Content Security Policy; the guide lists what a header must allow.

05 Honest status

Where it is, and what's next.

The file engine came first: reading, modelling and writing a deck without losing anything. Now it ships in thin slices you can use, each one deepened in later passes.

  1. Phase 1
    Model, import and export
    Bounded reading of the package, the whole format modelled, recovery of damaged decks, and a writer that patches only what changed. Every tier is closed.
    Tiers closed
  2. Slices 1–4
    View, desktop, save and export
    The browser viewer, the desktop app, Save, PDF and PNG. Built and running; drawing is deepened slice by slice, tables, charts and effects first.
    In progress
  3. Slices 5–8
    Edit text, move shapes, present, build slides
    Typing and formatting with undo, moving and resizing shapes, presenter view with notes, then new slides, shapes and pictures with autosave.
    Next
  4. Later
    Co-editing, and a check against PowerPoint
    Real-time collaboration on a server you run. Before any release, our output is checked in PowerPoint itself; until then, nothing claims to match it.
    Planned
