Your decks, open anywhere.

OpenPresent is an open-source presentation editor for PowerPoint files. Open a .pptx in your browser or on your desktop, edit its text, shapes and slides, present it full screen, and export PDF or PNG. Your file never leaves your machine.

01 What it does

Open, edit, present, export. In the open.

A presentation editor with the ribbon and shortcuts you already know, over an engine whose first job is to keep your file intact.

.pptx · .pptm · .ppsx · .potx

Opens your decks. Never drops anything quietly.

Shapes, text, pictures, tables, charts, SmartArt and themes are read into one model. Anything the model does not hold yet is kept byte for byte, and what a slide uses that is not drawn yet is named, feature by feature.

Recovery

Opens damaged decks.

A truncated archive, broken XML or a missing content-types part gets the best reading we can make, and the deck opens. Hostile content is neutralized rather than obeyed; only a file with nothing readable in it is refused, naming why.

Edit

Edit text, shapes and slides.

Click into a text box and type, with bold, italic, underline and undo. Move, resize, rotate and delete shapes; add slides, text boxes, shapes and pictures; change the theme and slide size.

Slide show

Present it.

Full screen from the start (F5) or the current slide (Shift+F5), with PowerPoint's keys. Presenter View shows the next slide, your notes and a timer.

PDF · PNG · .pptx

Save and export.

Save gives back a .pptx: parts you did not touch come back byte for byte, and an edit patches only what changed. Export a PDF with real, searchable text, or a slide as a 1920-pixel PNG.

Web · desktop

In the browser, and a desktop app too.

The same editor in a native window for macOS, Windows and Linux. Open a deck from the Open panel, or double-click a .pptx; no network needed. The desktop builds are early, unsigned previews.

Apache-2.0 · Rust · no telemetry

Open source, all the way down.

The engine, the editor and the desktop shell are on GitHub. unsafe is forbidden, every parser is bounded and fuzzed, and coverage of the format is measured row by row.

02 Private by design

Your deck never leaves your device.

The engine is compiled to WebAssembly and runs inside your browser, or inside the desktop app. There is no server to send a deck to: opening, drawing, editing and exporting all happen on your machine.

Your browser or desktop
  1. your .pptx
  2. engine · WebAssembly
  3. edit · present
  4. .pptx · PDF · PNG
Nothing goes out.

No upload, no account, no telemetry. Macros are never run, and links inside a deck are never fetched.

The editor

A ribbon you already know.

PowerPoint's tabs, groups and shortcuts, with every command it has present. What this build cannot do yet is shown disabled, with the reason in its tooltip, rather than faked.

06 Self-hosted

Put the editor on your own site.

The editor is static files: HTML, JavaScript, CSS and one WebAssembly engine. There is no server component, because a deck is opened and drawn in the visitor's own browser and never sent anywhere. Any web server, or any static host, will do.

08 Questions

Frequently asked

Is OpenPresent free?

Yes. It is open source under the Apache-2.0 licence: free to use, to change and to host yourself, with no account and no licence check.

Is my presentation uploaded anywhere?

No. The engine runs as WebAssembly inside your browser, or inside the desktop app. The deck is read from the file you pick and never sent to a server, and the site loads no trackers and no third-party scripts or fonts.

Which files does it open?

.pptx, .pptm, .ppsx, .ppsm, .potx and .potm: the Office Open XML formats PowerPoint has saved since 2007. The older binary .ppt format is not read.

Does it look exactly like PowerPoint?

We do not claim that. Our renders are compared with LibreOffice's in the public slide gallery, and some features are not drawn yet; each slide names what it leaves out. Before any release our output will be checked in PowerPoint itself.

Will saving change my file?

Saving a deck you have not edited gives back the same bytes. When you edit, only the parts you changed are rewritten, node by node; everything else, including what OpenPresent does not model yet, is kept as it was.

What about macros?

Macros are never run. A .pptm opens, and its macro project is kept in the file untouched, so saving does not strip it.

Can I use it offline?

Yes, with the desktop app for macOS, Windows and Linux. Today the builds are early, unsigned previews made by our CI; the download page explains the one-time step each system needs.

How can I help?

Try your own decks, and when one opens wrongly, open an issue with the file if you can share it. A star on GitHub helps others find the project.
