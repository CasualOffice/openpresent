# Real decks (`F-007`)

The first decks to reach this code that we did not write. **Every file here is hostile
input and third-party material.** Nothing in them is ever run, and no script from them.

Part of [NOTICE](../../NOTICE). Each committed file keeps its own licence below and is not
relicensed by this repository's Apache-2.0. Unmodified. The attribution CC BY requires is in
the table.

## What this proves, and what it does not

These decks show that the engine opens what PowerPoint wrote, and keeps it. They **cannot
show we match PowerPoint** (`DEC-04`, `PV-01`). The writer column is the file's own
`docProps/app.xml`, which is evidence and can be false: one deck found in this search
claimed PowerPoint while its Company field named a JavaScript library, and was dropped.

**Not satisfied here:** `STRICT-01`'s gate, a PowerPoint-saved Strict deck. The `sdk-strict-*`
files use Strict namespaces with Transitional numeric values (`val="50000"`), a byte order
mark and 2011 and 1980 timestamps, and report PowerPoint 14.0. They look converted by a
tool, not saved by PowerPoint. They are kept as a test of that odd form, nothing more.

## Rights

Licences were read on 2026-11-07 from Zenodo's API for each record, and from GitHub's licence
API for the Open XML SDK. **This is a rights review by an engineer and not legal advice; it
is part of `DEC-07`.** A deck's licence does not by itself clear a third party's picture
embedded in it, so committed Zenodo decks were chosen with few or no images, and searched for
copyright marks, stock-photo names and confidentiality wording. Images were not looked at one
by one. If a rights holder objects, the file goes.

Download dates are local. Files under 5 MB only are committed. Anything else is tested
locally: `python3 -I tools/real-decks/fetch.py DIR`, into a new empty directory, fetches every
row below and refuses a file whose SHA-256 differs.

Licence-restricted decks found and **not downloaded**: Zenodo 15731976, 15731955, 15731802
(CC BY-NC-SA 4.0), 18224131 (CC BY-NC-ND 4.0), 19297439 (CC BY-NC 4.0).

## Keynote and Google Slides (`CORP-01`, `F-009`)

Surveyed 2026-11-08: 537 openly licensed decks under 5 MB, from part of Zenodo and 13 permissively
licensed GitHub repositories. **No deck named Keynote in `docProps/app.xml`, so none is
committed as Keynote's.** 128 report `Microsoft Macintosh PowerPoint`, and nothing here tells
whether any of those came from Keynote, so they are not counted as Keynote's.

The Google Slides test is structural, because these exports carry no writer name: no
`docProps/app.xml`, and shapes named `Google Shape;N;pN`. 23 decks met it. Another 15 have those
names but also an app.xml naming PowerPoint, which reads as a later PowerPoint save, so they
do not count. Google did not state any of this, so it is strong evidence and not proof.

The `gs-` and `z17301875` decks were not run through `tools/real-decks/check.py`, so they have
no row under Results yet. Their images were not looked at; `gs-z11091145` has one and
`z17301875` six small ones. A Morph search matched only the word, without checking for a
Morph transition, so no deck is recorded as Morph. No Zoom marker was found.
